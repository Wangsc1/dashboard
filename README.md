# dashboard

运行于 iPhone **Scripting** 的 OpenWrt 与独立 Clash/Mihomo 控制器管理面板。

支持 OpenWrt 上的 **Nikki / OpenClash / MihomoTProxy** 插件，以及直接连接 Clash/Mihomo 控制器。系统监控需要 OpenWrt；配置、订阅、附加规则和服务管理为 Nikki 专用，不会向其他插件套用 Nikki 接口。功能是否可用取决于插件、内核版本、设备权限和 Scripting 版本。

## 功能

### 主页与 CPU 详情

- CPU、上传/下载速率与累计流量、内存、1/5/15 分钟负载、磁盘容量和连接数。
- OpenWrt 在脚本前台持续采样，切换标签仍保持采样；后台停止。同来源恢复时复用已有历史，不是后台监控服务，也不生成设备历史报表。
- 点击 CPU 卡片查看系统信息、总 CPU 和全部已读取的逻辑核曲线，以及设备实际提供的频率、缓存等元数据；支持左上关闭和下拉关闭。
- CPU 使用率来自计数差分；未知值不伪造为零。负载不是 CPU 百分比，磁盘只显示设备返回的挂载点和容量，不推断硬件型号。
- 主页与详情共用本地 Canvas 曲线，图表不请求外部资源。无读取权限或字段缺失时显示未知或降级内容；独立控制器不提供 OpenWrt 系统指标。

### 代理、规则与连接

- **代理**：策略组、节点选择、延迟测速与排序、代理来源查看与单独更新；支持显示图标、隐藏组等展示偏好，以及切换节点后自动断开旧连接的可选行为。
- **代理模式**：规则 / 直连 / 全局分段选择，读取并核验内核实际模式；未知时不冒充已选中。确认全局模式后显示 GLOBAL 策略组。
- **测速设置**：代理页内提供延迟阈值、测速链接和测速超时设置。节点测速共用并发队列，使用脚本设置的测试链接；实际耗时受内核、节点和网络影响。
- **规则**：内核规则查询、规则来源查看与更新，与 Nikki 的「附加规则」分开。
- **连接**：活动/已关闭记录、上下行速率、详情、搜索排序、同源/同域名筛选，以及断开单个或全部连接。已关闭记录只来自本脚本连续观察，不代表设备完整历史。

### 更多与设置

- **主题及启动**：浅色 / 深色 / 跟随系统，以及默认打开的标签页。
- **运行信息**：内核、插件版本和可读取的运行时间；检测到可用核心更新时在内核版本旁提示。未提供的运行时间不推算为已知值。
- **核心配置 → 代理配置**：各端口、允许局域网、IPv6、绑定地址、TUN 开关、日志级别，以及自定义请求头、嵌套组延迟显示偏好。这里修改内核当前运行配置，不等于修改 Nikki UCI 或配置文件，插件重启后可能覆盖。
- **快捷管理（Nikki）**：配置文件列表、选用与正文编辑；订阅新增/编辑/删除/更新；附加规则新增/编辑/删除、排序和总开关。
- **服务管理（Nikki）**：启动、停止、重启、重载。
- **核心操作**：升级核心、重启核心、重载配置、更新 GEO 数据库。能力取决于设备和内核接口；升级执行后续核验，不把请求发出当作升级成功。
- **DNS 工具**：刷新内核 DNS / FakeIP 缓存、域名查询，不是路由器 dnsmasq 缓存管理。
- **面板设置与运行日志**：多控制器管理、清除缓存、本地安全事件摘要及日志偏好、手动 iCloud 设置备份/恢复。
- **路由器详情**：网络接口、在线设备、Docker 概览/容器/镜像/参数、FRP 服务与配置、软件管理；具体内容依赖设备接口与权限。

## 导入、连接与在线更新

[在 Scripting 中导入](https://scripting.fun/import_scripts?urls=["https%3A%2F%2Fgithub.com%2FWangsc1%2Fdashboard"])

项目地址：[Wangsc1/dashboard](https://github.com/Wangsc1/dashboard)

1. 安装 Scripting 后通过上方链接导入并运行，在控制器管理中添加来源。
2. **OpenWrt**：填写自己的 LuCI 后台地址、端口、用户名和密码，不是代理控制器地址；选择插件。自动获取会读取对应插件的控制器端口和密钥，关闭后可手动填写。
3. **独立 Clash/Mihomo**：填写可访问的控制器地址、端口和密钥，不需要 LuCI 登录。
4. 使用底部 **主页 / 代理 / 规则 / 连接 / 更多** 切换页面，按提示完成校验和确认。地址和凭据由使用者自行填写，仓库不附带私人服务器配置。

仓库 `script.json` 保持以下在线资源配置，由 Scripting 处理检查和更新；间隔配置不保证设备一定按时完成更新：

```json
"remoteResource": {
  "url": "https://github.com/Wangsc1/dashboard",
  "autoUpdateInterval": 86400
}
```

实际导入、更新及原生导航表现以 Scripting 的处理结果为准；原生 Tab API 面向 iOS 18+。配置编辑器使用 Scripting 官方 `Editor` 与 `EditorController`，不再加载自建 HTML 或编辑器 bundle。

## Nikki 管理与编辑

### 配置文件

列表区分本地和订阅文件，显示大小、更新时间及 UCI 当前选用标记。点击卡片确认选用；勾选只表示选用配置，不证明内核已经成功加载。

正文编辑沿用原生导航，隐藏底部标签栏，提供官方键盘辅助栏、撤销/重做和查找/替换。官方未列出 YAML 扩展名支持，因此使用 `txt` 模式，不承诺 YAML 高亮、折叠或缩进线；不自动格式化或序列化 YAML，完整正文和换行保真仍需目标 App 验收。

**右上保存按钮显式保存，返回不自动写入远端。** 保存直接读取官方控制器的当前完整正文并确认覆盖，写后完整回读核对；成功后留在编辑页，可继续编辑，不自动应用或重载。读取未完成、不完整或来源已变时拒绝保存。保存按钮在读取成功后可用，以免约100毫秒的变更通知延迟漏掉立即保存；正文未变时不确认、不写入。未保存草稿按来源和文件保留在本次进程内存中，退出脚本后不会持久保存。

### 订阅与附加规则

- 订阅支持名称、URL、User Agent 和优先级；编辑使用本次打开的快照，不复用另一订阅的草稿。订阅/规则编辑及排序按返回流程保存，并在远端提交前提示影响。
- 更新订阅直接调用 Nikki 更新接口，会访问订阅地址并覆盖下载文件，包括对该文件的本地编辑，不是合并操作。删除需要确认；当前选用订阅不允许删除，普通删除仅删订阅设置、保留下载文件。
- 附加规则菜单提供排序、总开关和添加，支持编辑、删除；保存保留未知字段，排序保留非规则 section 的位置。基本输入会校验，复杂规则最终合法性由内核判断。

### 权限与写入限制

- UCI 提交可能触发 Nikki 自动重载并断流，不能保证「只保存、不生效」。相关提交前提示影响，脚本不额外发送重复重载；核心和服务操作也可能中断连接。
- 配置正文通过已认证的 LuCI CGI 完整下载并校验；只允许指定 Nikki 目录内的 YAML 普通文件，检查路径与符号链接，不修改 ACL 来绕过权限不足。
- 文件按 UTF-8 分块写入并回读校验，**不是原子替换**。中途失败可能留下部分文件，须先核对恢复，不要立即重载。
- 写入按来源串行，核对旧快照和未提交 UCI 改动，不提交或清理其他会话的 pending 改动。敏感写请求不会因认证过期而盲目重放。
- 设备端没有可用的原子 CAS，仍应避免同时通过 LuCI、订阅更新器或其他进程修改同一对象。接口返回成功不必然等于服务已成功加载配置。

## 来源隔离、缓存与隐私

- 控制器密码、密钥和自定义请求头使用 Keychain；连接信息与显示偏好保存在脚本本地。仅连接可信设备，妥善保护手机、路由器账户和网络访问权限。
- 页面按来源复用数据再刷新；不同页面按各自策略保留内存或非敏感本地快照。缓存不是设备实时状态或离线备份。
- 代理配置复用同来源非敏感字段的内存快照；无缓存时显示加载占位，不把尚未读取当作「未提供」，刷新不覆盖正在编辑的草稿。
- Nikki 配置/订阅/附加规则管理复用同来源上次成功读取结果并静默刷新，首次无缓存才显示读取中；刷新失败保留内容并显示错误，重新读取成功前阻止基于旧数据写入。写成功后失效缓存重读。
- **路由器详情预取**：进入面板设置时预取网络接口、在线设备、Docker 概览/容器列表/镜像列表/参数和每容器详情、FRP 服务及配置、软件已安装/可用列表和磁盘用量；镜像详情复用父页面对象，FRP 通用/代理编辑复用已读配置，本地日志同步读取。资源读取链最多并发两条，同资源在途去重；详情有快照则直接显示并静默刷新，无缓存时仍需等待读取。
- 路由器详情缓存只在进程内，按含认证身份的来源隔离；切源、后台或写后失效会拒绝旧读取回填，恢复前台后可重试。刷新失败不伪造成功，写入确认保留；Docker 参数等已编辑草稿不会被静默刷新覆盖。预取不保证进入每个子页时都已完成。
- 订阅 URL、UCI 快照、配置正文及可能包含私密配置的路由器详情数据只留在内存，不写普通日志、Storage 或云备份。
- 本地「运行日志」是安全事件摘要，不是 OpenWrt `logread` 或内核原始日志；不记录请求/响应正文、URL、密码、密钥或 session。Nikki 远端日志入口通过设备自己的 LuCI 查看，不复制进本地摘要。
- iCloud 为手动设置备份/恢复，可包含控制器地址、用户名及偏好，不含密码、密钥、请求头、日志、图片或 Nikki 正文。自定义测速链接可能含参数，备份前自行确认没有秘密；恢复不等于凭据同步，也不保证跨设备立即收到。

## 开发与验证

使用 Scripting 官方组件与全局 API，不依赖 Scriptable。主测试及专项使用模拟网络、存储和 UI；编辑器专项模拟官方控制器契约及延迟通知，不代替 iPhone 的实际编辑器、导航手势、键盘、安全区、实际权限与性能验收。

```sh
node tests/run.cjs
node tests/router-details-prefetch.cjs
node tests/kernel-config-loading.cjs
node tests/management-cache.cjs
node tests/proxy-mode.cjs
node tests/proxy-settings-menu.cjs
node tests/nikki-management.cjs
node tests/nikki-editors.cjs
node tests/nikki-file-lifecycle.cjs
node tests/core-upgrade.cjs
node tests/core-update-check.cjs
node tests/home-root-sampling.cjs
node tests/plot-host.cjs
git diff --check
```

其他专项见 `tests/*.cjs`。测试默认使用 `/tmp/chk/node_modules/typescript`，可通过 `TYPESCRIPT_PATH` 指定已有 TypeScript 包；业务类型检查使用 `tests/business-stub.d.ts`，它不是目标 App 的完整官方类型声明。

配置编辑器无需单独构建；官方控制器行为由 `tests/editor-mock.cjs` 按文档建模，不代表 SDK 内部实现。
