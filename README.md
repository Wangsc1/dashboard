# Neko Dash for Scripting

非官方实现：在 iPhone「Scripting」中管理 Clash（Mihomo / OpenClash / OpenWrt）与 Surge 控制器。

功能：多控制器管理、实时速度/累计流量/连接数、运行模式切换、策略组节点切换与测速、连接列表与断开、规则预览与筛选、Clash 内核配置（日志级别/端口/允许局域网）、主屏与锁屏小组件。

使用：运行脚本 → 设置 → 添加控制器。Clash 填 external-controller 地址与 Secret；Surge 填 http-api 地址与 key（需在 Surge 开启 http-api）。密钥存 Keychain。
